# vision-meter-reader

基于计算机视觉的仪表读数识别工具，自动从燃气表等设备的 LCD 数码管屏幕照片中提取并识别数值读数。

## 项目简介

`vision-meter-reader` 通过 OpenCV 实现一套完整的「视觉抄表」流程：对仪表屏幕照片做透视矫正与二值化预处理，再对七段数码管数字进行连通域分割与逐位识别，最终输出完整的读数数值（含小数点）。

整个流程无需训练模型，纯传统图像算法即可工作，适合固定机位、固定角度拍摄的仪表读数场景。

## 核心特性

- **透视矫正**：基于四个角点做透视变换，将倾斜拍摄的 LCD 屏幕拉正。
- **图像预处理**：灰度化 + 高斯模糊 + 自适应阈值二值化 + 形态学闭运算。
- **斜体扶正**：针对斜体 LCD 字体，通过全局剪切变换把数字整体拉直。
- **七段数码管识别**：按段区域统计行/列覆盖率判断亮灭，映射到 `0-9`，并支持汉明距离容错。
- **小数点检测**：在未膨胀原图上单独识别紧凑小方块，排除货币符号（如 `¥`）等干扰。

## 项目结构

```
vision-meter-reader/
├── main.py                 # 主流程：预处理 + 分割 + 七段数码管识别
├── get_roi_coordinates.py  # 辅助工具：鼠标点击获取 ROI 角点坐标
├── requirements.txt        # Python 依赖
└── image.jpg               # 测试用仪表截图
```

## 环境依赖

- Python 3.8+
- OpenCV >= 4.8.0
- NumPy >= 1.24.0

安装依赖：

```bash
pip install -r requirements.txt
```

## 快速开始

### 1. 获取 ROI 角点坐标

先用辅助工具在仪表照片上标定屏幕的四个角点：

```bash
python get_roi_coordinates.py
```

在弹出的窗口中依次点击屏幕的**左上、右上、右下、左下**四个角点，记录终端打印的坐标。

### 2. 填入坐标并运行识别

将上一步得到的坐标填入 `main.py` 中 `Config.pts_src`：

```python
pts_src = np.array([
    [647, 306],   # 左上
    [1168, 307],  # 右上
    [1159, 518],  # 右下
    [653, 511],   # 左下
], dtype=np.float32)
```

所有仪表标定参数集中在 `main.py` 顶部的 `Config` 数据类中，换表时仅需修改此处：

```python
@dataclass(frozen=True)
class Config:
    pts_src: np.ndarray = ...          # 透视矫正四角点
    warp_size: Tuple[int, int] = ...   # 矫正后尺寸
    global_shear: float = 0.06         # 斜体剪切因子
    digit_region: Tuple[float, ...]    # 数字区域比例范围
    on_threshold: float = 0.6          # 段亮灭阈值
    ...
```

辅助工具也支持命令行传参：

```bash
python get_roi_coordinates.py image.jpg   # 可指定任意图片路径
```

准备一张测试图片 `image.jpg` 放在项目根目录，然后运行：

```bash
python main.py
```

### 3. 查看结果

程序会在终端打印识别结果，并输出调试图片：

```
原始识别字符串: 12.35
当前识别出的完整数值为: 12.35
```

同时生成以下调试文件，便于排查识别效果：

- `dbg_warped.png`：透视矫正后的屏幕图像
- `dbg_binary.png`：二值化后的图像
- `dbg_result.png`：数字分割与识别结果（带框标注）

## 识别原理

1. **预处理**：透视矫正 → 灰度 → 模糊 → 自适应二值化 → 形态学闭运算。
2. **数字分割**：对数字区域做斜体扶正与竖向膨胀，用连通域轮廓提取每个数字的外接框。
3. **逐位识别**：按七段编码采样各段覆盖率判断亮灭，映射为 `0-9`；窄字直接判为 `1`。
4. **结果组装**：单独检测小数点并按水平位置排序，拼出最终读数。

## 使用说明

- 本项目针对**固定型号燃气表 LCD 屏**标定，`Config` 中的 `pts_src`、`global_shear`、`digit_region` 等参数需根据实际仪表重新调整，亦可实例化新 `Config` 传入各函数。
- 若识别精度不足，可优先检查二值化效果（`dbg_binary.png`）与角点标定是否准确。
- 调试窗口需 GUI 环境；无显示环境时可使用 `cv2.imwrite` 输出结果查看。
